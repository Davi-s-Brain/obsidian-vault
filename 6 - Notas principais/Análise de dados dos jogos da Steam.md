# Análise de dados dos jogos da Steam

## Resumo
Projeto de análise de dados do perfil Steam: correlação entre notas, backlog, compatibilidade com Steam Deck, categorias e tempo de jogo, usando Python e R.

## Conteúdo

O projeto tem como intuito analisar o meu perfil da Steam, bem como os jogos presentes nele.

## Análises que serão feitas

- Correlação entre nota no Metacritic e tempo de jogo
- Análise do backlog em comparação com as notas do Metacritic
- Os jogos que estão como Verified para o Steam Deck tem um pompo de jogo maior?
- Quais as categorias mais jogadas?
- Outras análises

## Tecnologias

- Python, para extração dos dados e criação de um CSV inicial
- R, para análise e geração de gráficos
