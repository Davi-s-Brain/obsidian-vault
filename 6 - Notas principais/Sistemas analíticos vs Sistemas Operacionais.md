# Sistemas analíticos vs Sistemas Operacionais

## Conteúdo
*Sistemas operacionais*: Consistem em sistemas de backend e na infraestrutura de dados, em que são gerados esses dados, ao atender usuários por exemplo. Assim, o código da aplicação lê e modifica os dados nos bancos de dados com base nas ações realizadas pelos usuários.

> [!important] Esses sistemas operacionais se referem as aplicações, e não a sistemas como o Windows ou Linux!

*Sistemas analíticos*: Esses sistemas são projetados para atenderem as necessidades de analistas de negócios e de cientistas de dados. Contém apenas uma cópia *read-only* dos dados que vem dos sistemas operacionais e são otimizados para fazer essas análises.
